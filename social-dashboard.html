API Setup

Connect your social media accounts to enable direct publishing from this dashboard. The backend server must be running.

f

Meta — Facebook & Instagram

One API connection covers both platforms via Meta Graph API v18+

Not Connected
1

Create a Meta Developer App

Go to developers.facebook.com → My Apps → Create App. Choose "Business" type. Add the "Pages API" and "Instagram Graph API" products.

2

Get a Page Access Token

In the Graph API Explorer, generate a long-lived Page Access Token with permissions: pages_manage_posts, instagram_content_publish, pages_read_engagement

3

Find Your Page ID and IG User ID

Call GET /me/accounts to get your Facebook Page ID. Then call GET /{page-id}?fields=instagram_business_account for your IG User ID.

♪

TikTok Content Posting API

Requires TikTok Developer account and business approval for Content Posting API

Not Connected
1

Register as a TikTok Developer

Go to developers.tiktok.com → Create App. Choose the "Content Posting API" product. You'll need a TikTok Business or Creator account.

2

Authorize and Get Access Token

Complete the OAuth flow. Required scopes: video.publish, video.upload. Store the access token and refresh token securely.

3

Upload Videos via Direct Post API

Use POST /v2/post/publish/video/init to initialize an upload, then send the video file, then call /publish/status/fetch to confirm.
